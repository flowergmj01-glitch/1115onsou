序章　日本旅遊常見的三種「如果」

〜たら（萬用、做完某事之後）

京都に着いたら、まず清水寺へ行きます。

到了京都之後，先去清水寺。

雨が降ったら、電車で行きましょう。

如果下雨，就搭電車去吧。

〜ば（只要具備這個條件）

地図があれば、一人で行けます。

有地圖的話，我一個人就能去。

安ければ、お土産をたくさん買います。

如果便宜，我會買很多伴手禮。

〜と（一做就發生、機器與路線）

このボタンを押すと、切符が出ます。

一按這個按鈕，車票就會出來。

春になると、京都は桜がきれいです。

一到春天，京都的櫻花就很美。

作答分配：單數題請 おんさん 回答，雙數題請 そうさん 回答。

① 〜たら

怎麼用

意思：「如果…的話」或「做完…之後」。
最百搭，後面可以接「想做某事、約人、拜託別人」。也可以用來說「一做某事，才意外發現…」。

怎麼接

詞類變法例子
動詞た形 ＋ ら行く → 行ったら／飲む → 飲んだら／食べる → 食べたら／する → したら／来る → 来たら
い形容詞去い ＋ かったら安い → 安かったら
な形容詞・名詞＋ だったら静か → 静かだったら／雨 → 雨だったら

② 〜ば

怎麼用

意思：「只要…就…」。
重點放在「要達成什麼條件」。如果後句想接「走吧、請幫我」，前句通常是狀態（像是 ある、ない、形容詞）。

怎麼接

詞類變法例子
一類動詞u段音 → e段音 ＋ ば書く → 書けば／飲む → 飲めば／行く → 行けば
二類動詞去る ＋ れば食べる → 食べれば／見る → 見れば
三類動詞固定變法する → すれば／来る → 来れば
い形容詞去い ＋ ければ高い → 高ければ／いい → よければ
な形容詞・名詞＋ であれば（口語常說 なら）静か → 静かであれば

暖身：字尾變化

③ 〜と

怎麼用

意思：「一…就一定會…」。
用在機器操作、報路、自然現象或固定習慣。注意：後句絕對不能接「我想、走吧、請你…」這種人為想法！

怎麼接

詞類變法例子
動詞原形（辞書形）＋ と見る → 見ると／押す → 押すと／する → すると／来る → 来ると
い形容詞直接 ＋ と安い → 安いと
な形容詞・名詞＋ だと静か → 静かだと／春 → 春だと
